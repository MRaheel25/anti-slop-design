# Type Guide — Brand / Graphic

## Craft rules

- Start from the story and the voice, not from a template. A brand
  system is a language: type roles, colour roles, spacing, imagery
  rules, and voice — written down so someone without a designer can
  follow it.
- Type: one display role, one body role, sizes and weights named.
  Colour: 4–6 tokens with roles, never a palette with no job.
- Imagery: one style, stated plainly (photography of real people
  in real places, flat illustration, 3D, none). Mixed styles without
  a rule look accidental.
- Layout: one grid, one radius system, one spacing scale. Variation
  comes from composition, not from inventing a new system per piece.
- Print specs are part of the design: bleed, CMYK, paper, finishes,
  minimum sizes. A poster that cannot be printed is unfinished.
- Guidelines must be usable: do and don't examples, file naming,
  and where the assets live. If the guidelines need the designer
  in the room to be understood, rewrite them.

## Anti-slop for brand and graphic work

- No template-looking system: the same card, the same gradient wash,
  the same icon row on every piece.
- No invented values, invented testimonials, or invented client
  lists in brand materials.
- No "premium" claimed in words while the craft is generic. Premium
  is shown in spacing, type, and restraint.

## Research notes for brand work

Research the closest brands in `references/design-systems/` and in
awesome-design-md (inferred tokens are hypotheses). Extract: how
colour and type carry the brand when the logo is removed, how
photography is treated, how much empty space is allowed. Record
what was not copied.

## Deliverable

The pieces named in the intake (poster, deck, stationery, social
templates, guidelines), plus a one-page system summary: tokens,
type roles, imagery rule, and do / don't.
